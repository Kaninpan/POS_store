# Shop POS

ระบบจัดการร้านค้าและขายหน้าร้าน พัฒนาด้วย PHP และ MySQL/MariaDB

## ฟังก์ชันหลัก
- ภาพรวมยอดขายและสต็อก
- จัดการสินค้าและบาร์โค้ด
- รับสินค้าเข้าและปรับยอดสต็อก
- ขายสินค้า ค้นหาหรือสแกนบาร์โค้ด และจัดการตะกร้า
- ประวัติการขายและรายงานสินค้า
- แบ่งหน้ารายการ และพิมพ์ฉลากบาร์โค้ด
- หน้าต่างแจ้งเตือนและยืนยันรายการแบบมี animation

## การใช้งาน
1. วางไฟล์ PHP ในโฟลเดอร์โปรเจกต์บน XAMPP
2. ตั้งค่าการเชื่อมต่อฐานข้อมูลใน `config.php`
3. ใช้ฐานข้อมูล `shop_pos` ที่มีตารางตามระบบ
4. เปิดผ่าน `http://localhost/test/`

ต้องมี `config.php` และฐานข้อมูลที่ตั้งค่าไว้ก่อนใช้งาน การสแกนด้วยกล้องต้องใช้ `localhost` หรือ HTTPS และอนุญาตสิทธิ์กล้องในเบราว์เซอร์
